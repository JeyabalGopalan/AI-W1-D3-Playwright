# 📈 TradingView Markets Automation using Playwright

A beginner-friendly Python automation project that uses **Playwright** to open TradingView, navigate to the Markets section, extract visible market information, take a screenshot, and save the extracted information into a text file.

This project demonstrates how browser automation can be used to collect information from a dynamic website.

---

## 📌 Project Overview

The automation performs the following tasks:

Chromium
   ↓
TradingView
   ↓
Find "Markets"
   ↓
Click "Markets"
   ↓
Wait for page
   ↓
Extract page information
   ↓
Take Screenshot
   ↓
Save extracted text
   ↓
Close Browser

---

## 🎯 Objective

The main objective of this project is to learn how to automate a real website using **Python and Playwright**.

The project focuses on:

- Browser automation
- Element identification
- Waiting for webpage elements
- Extracting webpage text
- Taking screenshots
- Saving extracted information
- Handling a dynamic website

---

## 🛠️ Technologies Used

### Python

Python is used as the main programming language.

### Playwright

Playwright is used to control the Chromium browser and interact with the TradingView website.

### Chromium

Chromium is the browser controlled by Playwright.
